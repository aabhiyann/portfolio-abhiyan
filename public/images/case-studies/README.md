## Image Guidelines

- **Format:** PNG or WebP (preferred for smaller file size)
- **Size:** Max width 1200px (optimize for web)
- **Naming:** Use descriptive names like `forecasting-dashboard.png`, `anomaly-detection.png`
- **Quality:** Balance between file size and clarity (80-90% quality for WebP)

## How to Add Images

1. Take screenshots of your live app
2. Optimize them (use tools like ImageOptim or Squoosh)
3. Save them in the appropriate project folder
4. The case study will automatically display them
