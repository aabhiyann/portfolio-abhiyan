## Image Guidelines

- **Format:** PNG or WebP
- **Size:** Max width 1200px
- **Quality:** 80-90% for WebP
- **Privacy:** Redact any sensitive information

## How to Take Screenshots

1. Run your app locally or on a test deployment
2. Use sample documents (public domain PDFs)
3. Create realistic chat conversations
4. Capture clean, professional screenshots
5. Optimize images before adding them here

Once you add the screenshots, they'll automatically appear in the case study!
