## Key Themes

All versions emphasize:
1. **Transfer learning isn't always better** — 26% improvement with task-specific training
2. **Domain alignment matters** — Mismatch between AudioSet and focused task
3. **Regularization is critical** — Dropout(0.5) reduced loss from 0.57 → 0.24
4. **Complexity ≠ Performance** — Simple CNN (92%) beat CRNN (78.69%) and ViT (35-40%)
5. **Research methodology** — Systematic experimentation, proper evaluation
